# Screenstreet - Многоязычный туристический гид по Астане

Современное веб-приложение с многоязычной информацией о достопримечательностях Астаны через QR-коды.

## Возможности

- **10 главных достопримечательностей** — Подробная информация о знаковых местах Астаны
- **Поддержка 7 языков** — Казахский, русский, английский, китайский, турецкий, немецкий, французский
- **Интеграция QR-кодов** — Быстрый доступ к информации о достопримечательностях через сканирование
- **Ссылки на 2GIS** — Прямые ссылки для перехода к месту и построения маршрута в 2GIS
- **Адаптивный дизайн** — Работает на десктопе и мобильных устройствах
- **Темная тема** — Удобный интерфейс для любого освещения

## Технологический стек

### Фронтенд
- **Next.js 15** с App Router
- **TypeScript** для типобезопасности
- **Tailwind CSS** для современного адаптивного UI
- **Framer Motion** для плавных анимаций
- **Lucide React** для красивых иконок

### Сервисы
- **Unsplash** — Качественные изображения достопримечательностей
- **Генерация QR-кодов** — Автоматическое создание QR-кодов для каждой точки

## Быстрый старт

### Требования
- Node.js 18+
- npm или yarn

### Установка

1. Клонируй репозиторий
```bash
git clone https://github.com/ERROR-SANS-566/screenstreet.git
cd screenstreet
```

2. Установи зависимости

```bash
npm install
```

3. Запусти dev сервер

```bash
npm run dev
```

Открой http://localhost:3000 в браузере — произойдёт редирект на /ru.

Сборка для продакшена

```bash
npm run build
npm start
```

Деплой на Vercel

Проект настроен под обычный деплой на Vercel:

· Нет basePath, assetPrefix, output: "export".
· vercel.json содержит редирект / → /ru.

Подключите репозиторий к Vercel — сборка и деплой произойдут автоматически.

Ожидаемый адрес: https://screenstreet.vercel.app/

При открытии корня / браузер автоматически переходит на /ru.

Добавление достопримечательностей

Чтобы добавить новые места, отредактируй data/places/astana.ts:

```typescript
{
  id: '11',
  slug: 'new-landmark',
  category: 'landmark',
  address: 'Адрес улицы, Астана',
  dgisUrl: 'https://2gis.kz/astana/firm/xxxxx',
  images: [
    {
      url: '/images/landmarks/new-landmark.jpg',
      alt: 'Новая достопримечательность',
    },
  ],
  translations: {
    en: { name: '...', description: '...', history: '...', facts: ['...'] },
    ru: { name: '...', description: '...', history: '...', facts: ['...'] },
    kk: { name: '...', description: '...', history: '...', facts: ['...'] },
    zh: { name: '...', description: '...', history: '...', facts: ['...'] },
    tr: { name: '...', description: '...', history: '...', facts: ['...'] },
    de: { name: '...', description: '...', history: '...', facts: ['...'] },
    fr: { name: '...', description: '...', history: '...', facts: ['...'] },
  },
  nearbyPlaceIds: ['1', '2'],
}
```

Добавь фотографии в директорию public/images/landmarks/.

Координаты указывать не нужно — они не используются.

Добавление переводов

Переводы управляются в data/translations/index.ts. Переводы контента (описания, истории) созданы с помощью инструментов перевода для точности во всех 7 поддерживаемых языках.
